# Mardin Şehir Rehberi (.Net Maui - .Net 10 Android)

## Projenin Temel Maksadı
Mardin Şehir Rehberi, Türk kullancılarının Mardin şehri hakkında bilgi sahibi olabileceği, gidilip görülmesi lazım gelen mekanlar hakkında bilgi sahibi olabilecekleri, gerekirse nasıl ve ne şekilde gidebileceklerini kolaylaştıran bir mobil uygulamasıdır.

.Net Maui -.Net Android 10.0 temelli, SqLite ve xaml teknolojileri geliştirme esnasında kullanıldı.

"Proje işinize yaradıysa veya referans almak isterseniz GitHub üzerinden bir ⭐ bırakarak destek olabilirsiniz, şimdiden teşekkürler!"

## Kullanılan Teknolojiler
### Backend
💎 .Net Maui - Android 10.0 <br />
💎 SqlLite <br />
💎 Google Gemini: Veri Hazırlama <br />
💎 Google Cloud Console: Maps SDK For Android <br />


### Frontend
💎 Xaml <br />
💎 Stitch AI: Kullanılan Temanın Html Formatta Hazırlanması <br />
